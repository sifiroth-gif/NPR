При внимательном наблюдении Шики увидел тонкий чёрный волос, соскользнувший с воротника Саске на светлый халат у стола; волос пока никто не поднял. Кабуто затем предложил совместный проект по древнему мёртвому наследственному образцу с пока скрытым именем донора.
