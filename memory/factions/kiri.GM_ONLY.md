# kiri · фракция

ТОЛЬКО ВЕДУЩИЙ. Раскрывается только сыгранным.

- **who:** Охотники Тумана.
- **wants:** Вернуть или уничтожить вынесенные линии крови.
- **has:** Ойнины, право преследования за границей по старым соглашениям.
- **trigger:** Хьётон или гидратация при свидетелях, которые доживут до рассказа. Срок от слуха до первой пары охотников: две-три недели.
- **to_shiki:** Тело на вскрытие. Переговоров не ведут.
