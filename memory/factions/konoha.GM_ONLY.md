# konoha · фракция

ТОЛЬКО ВЕДУЩИЙ. Раскрывается только сыгранным.

- **who:** Разведка Листа и отдельно Корень.
- **wants:** Чтобы ткань и глаза своих кланов не ходили по рукам. Корень хочет того же, но себе.
- **has:** АНБУ, архивы, давление на малую деревню.
- **will_cross:** Изъятие без суда. Корень собирает додзюцу и не оставляет свидетелей.
- **to_shiki:** Пока не замечен. Любой шаг к Шарингану делает его целью Корня раньше, чем конкурентом.
