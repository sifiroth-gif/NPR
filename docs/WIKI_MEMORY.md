# Вики мира (`memory/`)

Постраничная память кампании на ветке `game-state/shiki`. Её строит код `rpg_engine/wiki.py` при каждой свёртке. Руками страницы не правят: всё производное пересобирается из сыгранного.

## Что где

| Путь | Что лежит |
| --- | --- |
| `memory/INDEX.md` | Карта мира: по строке на персонажа, линию и вещь, с путём к странице |
| `memory/SCENE.md` | Текущая сцена: время, место, кто рядом, ближайшие сроки, конец последнего ответа |
| `memory/shiki.md`, `memory/shiki-fixes.md` | Шики и все поправки игрока о нём |
| `memory/npc/<id>.md` | Персонаж: постоянное, характер, сейчас, что знает, поправки, история |
| `memory/npc/<id>.knows.md` | Полный список знаний, если на странице показаны не все |
| `memory/npc/<id>.GM_ONLY.md` | Тайное: скрывает, психика, намерения, часы персонажа |
| `memory/threads/<id>.md`, `memory/threads/CLOCKS.GM_ONLY.md` | Сюжетные линии и часы мира |
| `memory/items/<id>.md` | Вещи |
| `memory/world-fixes.md` | Поправки игрока, не привязанные к одной странице |
| `archive/turns/sNN/<id>.md` | Ход целиком, все сессии; пометка, если ход заменён или отменён игроком |
| `archive/session-NNN-turns.jsonl` | Единый формат архива всех сессий; устройство в `archive/README.md` |
| `archive/deltas/session-NNN.jsonl` | Дельты `d` каждого хода: источник страниц |
| `memory/_curated/*.json` | Проверенные дополнения хранителя в формате `d` с полем `source` |

## Постоянное и текущее

- `look` — постоянная внешность, `facts` — возраст, пол, происхождение и другие черты. Новое значение становится текущим, прежнее остаётся строкой «прежде», а свёртка пишет в `CHECKS.json` замечание `stable_change`.
- `body` и `state` — только вид и положение в последней сцене. Постоянное они не затирают.
- Знания NPC (`knows+`) не обрезаются. На странице видны последние 25, все остальные лежат в `<id>.knows.md`.

## Новые персонажи

- Новый ключ в `d.cast` с `name`, `look` и `facts` сразу получает страницу и строку в INDEX.
- Если в сцене говорит персонаж **с именем** (`**Сато Кэн:**`), у которого нет ни страницы, ни карточки в этом ходе, свёртка пишет в `CHECKS.json` замечание `new_character`.
- Безымянный фон («Анестезиолог», «Медсестра», «Старший патруля», «Задержанный») подсказок не получает, даже если звучит во многих ходах. Значимого безымянного персонажа ведущий оформляет карточкой сам, как «Реципиент № 6».

## Команды

```bash
python -m rpg_engine wiki-backfill --state-dir STATE   # дельты прошлых ходов из истории TURN.json
python -m rpg_engine wiki-build --state-dir STATE      # пересобрать memory/ без свёртки
python -m rpg_engine archive-normalize --state-dir STATE  # сессии 1–3 в единый формат (разово)
```

Если `archive/deltas/` ещё нет, свёртка сама один раз восстанавливает дельты из истории git.
