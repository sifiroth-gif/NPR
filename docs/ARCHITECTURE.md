# Устройство NPR

## Два контура

| Контур | Для чего | Где |
| --- | --- | --- |
| **Живой (HOT v2)** | текущая сессия в чате: быстрый ход, память, давление мира | `rpg_engine/hot.py`, `recovery/` на `game-state/<кампания>` |
| **Архивный (SQLite)** | закрытые сессии: журнал, поиск, проверка знаний, бой | `rpg_engine/engine.py` и соседи, `campaign.sqlite` |

Ведущий — модель в чате с доступом к GitHub. Она не запускает код. Поэтому всё, что можно посчитать, считает GitHub Actions после её записи.

## Живой контур

```
ведущий ──(1 запись)──▶ recovery/TURN.json
                              │  push
                              ▼
                 .github/workflows/npr-live-memory.yml
                              │  python -m rpg_engine hot-fold
        ┌──────────────┬──────┴────────┬──────────────────────┐
        ▼              ▼               ▼                      ▼
recovery/HOT.json  recovery/      archive/session-NNN-   recovery/cast/
(открытое)         GM_ONLY.json   turns.jsonl (дословно)  <npc>.json
                   (скрытое)      chronicle.md (строки)
```

- **`recovery/TURN.json`** (`npr-turn/2`): заявка игрока, текст ведущего дословно, строка хроники, дельта состояния. Единственный файл, который пишет ведущий. Формат — `campaigns/shiki/GM_CORE.md`, раздел 3.
- **`recovery/HOT.json`** (`npr-hot/2`): курсор с датой и днём недели, календарь на две недели, сцена, состав с карточками (хочет, боится, чем давит, что знает, голос, тело), нити, тело Шики, договор со стадией, канон-поправки, хроника сессии, последний ответ дословно, отчёт проверки прозы. Не больше 72 КБ: хроника в нём ограничена 60 последними строками, полная лежит в архиве.
- **`recovery/GM_ONLY.json`** (`npr-gm-only/2`): скрытая правда, закадровые часы (владелец, действие, срок, след, исход без вмешательства), наступившие сроки, тайны NPC. В `HOT.json` от этого остаётся только счётчик.
- **`archive/session-NNN-turns.jsonl`**: все ходы сессии дословно, по строке на ход. **`archive/session-NNN-chronicle.md`**: все строки хроники.
- **`recovery/cast/<ключ>.json`**: карточки NPC без тайн. Убранный из сцены NPC остаётся здесь и возвращается в состав при первом упоминании в дельте.

`hot-fold` проходит по истории Git файла `TURN.json` от последнего свёрнутого коммита, так что несколько ходов подряд без CI не теряются. Старый `recovery/FAST_SCENE.json` тоже принимается: ход, записанный по прежней схеме, будет свёрнут. `hot-check` проверяет согласованность и то, что скрытое не попало в открытый файл. `hot-bootstrap` — разовая миграция со старой схемы.

Свёртка идемпотентна: повторный запуск без новых ходов ничего не меняет. Ошибочный ход не ломает состояние: он попадает в `HOT.fold.errors`, и ведущий видит его при следующем чтении.

## Проверка прозы

`rpg_engine/prose_lint.py` — детерминированный разбор текста сцены: оговорки об очевидном, толкования, описание отсутствующего, ритуалы согласия, утешения, названные чувства, обучающие пояснения, уклончивость, сводки безопасности, меню вариантов, внутренняя жизнь персонажа игрока, избыток «не X, а Y». Ничего не блокирует. Отчёт по трём последним ответам лежит в `HOT.lint`: ведущий видит цитаты собственных промахов перед следующей сценой. Та же программа приложена к навыку `skills/dark-literary-gm/`.

## Инструкции

| Файл | Роль | Предел |
| --- | --- | --- |
| `AGENTS.md` | маршрут: что читать и что писать | 6 000 знаков |
| `campaigns/shiki/GM_CORE.md` | правила кампании и цикл хода | 16 000 знаков |
| `skills/dark-literary-gm/SKILL.md` | манера письма | 8 000 знаков |
| `campaigns/shiki/ref/*.md` | медицина, бой, знание: по требованию | 6 000 знаков каждый |

Пределы проверяет `tests/test_instruction_budget.py`. Новая поправка заменяет строку, а не добавляет раздел. Прежние своды (`GM_PROTOCOL.md`, `SCENE_PREP_PRIORITY.md` и другие) оставлены на месте с пометкой «заменён», прежние `AGENTS.md` обеих веток — в `docs/legacy/`.

## Откат

Старые файлы не тронуты. Чтобы вернуться к прежней схеме: восстановить `AGENTS.md` из `docs/legacy/` и продолжить писать `recovery/FAST_SCENE.json`. Новые файлы (`HOT.json`, `GM_ONLY.json`, `TURN.json`, `archive/session-*-turns.jsonl`, `recovery/cast/`) можно оставить: прежняя схема их не читает.
