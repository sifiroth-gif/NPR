# D1: исторические регрессии

Закреплённый снимок: caa812cad7c00dae5337d32ba58756013917b209,
курсор s14.text.023. В workflow NPR isolated state audit читается весь
доступный корпус archive/session-*-turns.jsonl и archive/deltas/session-*.jsonl.
Объединение строго по ID, дубликаты и несовпадающие времена диагностируются.
Нормализация старых записей только в памяти по существующему адаптеру;
структурная совместимость проверяется hot.validate_turn. Отдельно считаются
записи без парного источника и legacy-строки без ключа d (допустимо по
hot.validate_turn; отсутствующая дельта остаётся неизвестной, не {}). Явное
null или не-объект по-прежнему ошибка. Это не полный повтор истории и не доказательство
корректности каждого сыгранного исхода: исходный посессионный state не
восстанавливается из неполных дельт.

Восемь проверок с первичными источниками:
- s10.text.018, s14.text.023 — освоенная стерилизация, переход предмета и повтор;
- s11.text.074, s13.text.077/.100 — сендзюцу, истощение, глаза;
- s14.text.015 и точные реплики — Минасэ, отсутствие глобального слияния;
- s14.text.007/.020/.021/.023 — воспроизведение травмы и частичного лечения;
- s14.text.012/.023 — уход из состава при сохранении клинического состояния;
- s10.text.084 — удалённый NPC не получает глобальную строку из приватного патча;
- 18 исходных + 4 мигрированных директивы сохраняются при переносе курсора;
- текущая сохранённая весть, повтор подтверждения — один факт доставки.

Синтетические сообщения/подтверждения используются только как вход в памяти,
не считаются событиями кампании. Защищены хеши всех доступных первичных
JSONL и Markdown ходов; workflow не имеет разрешения записи в репозиторий.
Результаты и числа — в журнале CI. D2 отдельно измеряет производительность.
