# Тематический контекст (B2)

NEXT — подготовленный пакет, не запрос к ещё неизвестному следующему сообщению.
В обычном чате ведущий читает его один раз, выбирает все подходящие темы
по **текущей** заявке, а не по последней архивной заявке. При «дальше»,
«продолжай», коротком согласии — `capabilities.scene_hint`, рассчитанный
по текущему проверенному scene (не по тайной части и не по прошлой заявке).
Активная схватка всегда требует боевого контекста, даже при диалоге.

`capabilities.routes.<тема>.required` — какие факты нужны до сцены;
`read` — адреса источников, не требование перечитать каждый файл.
Используй уже прочитанное, текущую локальную проекцию и NEXT.
Отсутствующая информация — адресное чтение, не выдумка. 
`state_sources` указывает на изменяемые факты: раны и функции, вещи,
исследования; состояние медкомплекта вынесено из HOT. Точный остаток
расходников не выводится из названия комплекта. Чужое знание только
из источника и канала; выбор маршрута не даёт нового знания NPC.

Пример: «достаю инструменты, лечу рану и спрашиваю врача» — items,
medical, dialogue; проверить доступность, функцию, чакру, время и знание.
«Магацухи» — точный алиас, требует актуального ВМШ и условий техники.
«Совместный покров» — найден, но unavailable; не разрешать как освоенный.
«Дальше» после операции — медицинский контекст, если состояние сцены это
подтверждает. Не считать, что действие игрока обязательно медицинское.

Локальный Python: `capabilities.for_request(data, action, scene=..., active_fight=...)`
возвращает темы, точные алиасы, обязательные поля, уникальные пути,
список возможных/недоступных возможностей; не выполняет действия.
`context_dispatcher.route` добавляет thematic к плану поиска для кампании
Шики. В обычном чате Python не вызывается автоматически: это контракт для
ведущего. Нет ожидания CI и нет обязательного дополнительного чтения.

NEXT сериализуется по одному блоку на строку, без вложенных отступов;
размер проверяется по фактическим байтам. Содержание не теряется от
сериализации. Каталог освоенного не повторяет статус для каждой записи,
недоступные формы обозначены явно; полный реестр остаётся источником.
